# 📈 Simple Linear Regression - Machine Learning Fundamentals

This repository contains an end-to-end implementation of **Simple Linear Regression**, a foundational algorithm in supervised machine learning. It demonstrates how to predict a continuous output based on a single input feature using Python and core data science libraries.

---

## 🎯 Objective

- Model the linear relationship between two continuous variables
- Learn the mathematics behind linear regression (hypothesis function, cost function)
- Fit the model using least squares estimation
- Visualize the regression line and residuals
- Evaluate model performance using standard metrics

---

## 🛠 Tools & Libraries

- Python 3.x
- NumPy
- Pandas
- Matplotlib / Seaborn
- scikit-learn

## 🔍 Key Concepts

**Hypothesis Function:**

    ŷ = β₀ + β₁x

**Cost Function (Mean Squared Error):**

    MSE = (1/n) * Σᵢⁿ (yᵢ - ŷᵢ)²


- **Model Evaluation**:
  - Mean Absolute Error (MAE)
  - Mean Squared Error (MSE)
  - R² Score (Coefficient of Determination)

---

## 📊 Learning Outcomes

- Understand and apply simple linear regression from both theoretical and practical perspectives
- Visualize the relationship between features and target variables
- Use scikit-learn and NumPy to implement and validate models
